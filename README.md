# Server Log Analyzer

A Python project that reads server log files, analyzes log levels,
identifies common errors, and exports reports.

## Features

- Parse server log files
- Count INFO, WARNING, ERROR, and CRITICAL entries
- Identify the most common errors
- Calculate error percentages
- Filter logs by date
- Export reports to JSON and CSV

## Technologies

- Python
- CSV
- JSON
- Pytest

## Run

```bash
python log_analyzer/main.py
```
